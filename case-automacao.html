Extração recorrente e conferência

Indicadores de vendas contra metas

Extrai resultados de um sistema de vendas várias vezes ao dia, mantém a sessão renovada de forma programada, compara com as metas e entrega o resumo; outro fluxo cruza uma planilha com o sistema para achar divergências.

  1. Renova a sessão antes de cada envio
  2. Extrai os indicadores
  3. Compara com as metas
  4. Entrega o resumo

Sistema sem API · sessão persistida · fila compartilhada · conferência entre duas fontes

Princípios de engenharia

  • Idempotência: o estado guardado evita reenviar o mesmo aviso, com limite de um envio por dia onde faz sentido.
  • Concorrência controlada: fluxos que compartilham sessão ou estado entram em fila, uma execução por vez.
  • Falha visível: erros disparam alerta para o administrador, e 13 dos 18 fluxos têm tratamento de erro.
  • Testes: 50 arquivos de teste cobrem a lógica de cada módulo, separada da automação de navegador.
  • Segredos e deploy: credenciais ficam no cofre do orquestrador, não no código, e o código em produção é sempre o do repositório principal.

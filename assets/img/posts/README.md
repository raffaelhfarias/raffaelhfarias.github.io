# Imagens dos posts

Esta pasta organiza os arquivos visuais usados no portfólio.

## Estrutura

- `covers/`: capas principais dos posts, usadas no `image:` do front matter.
- `previews/`: screenshots, GIFs e imagens internas usadas dentro dos posts.

## Padrão recomendado

- dimensão base: `1200 x 630 px`
- proporção: `1.91:1`
- formato preferencial: `PNG` para capas com texto e `JPG` para imagens fotográficas
- nomes de arquivo em `kebab-case`

## Exemplos de nomes

- `covers/churn-prediction-cover.png`
- `covers/cine-match-cover.png`
- `covers/gasolina-brasil-cover.png`
- `previews/cine-match-dashboard.png`
- `previews/covid-dashboard.gif`

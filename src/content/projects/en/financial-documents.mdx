## Technical decisions

The workflow keeps intake and delivery in the same channel and uses Kestra to orchestrate Python extraction and XLSX generation. That provides a simple operating path without exposing PDF contents.

## Reliability

The process returns a clear user message when an error occurs. There is no publishable historical measurement for retries, timeout, idempotency, validation, retention, access control, alerting, or partial failures.

## Results

The verified evidence is a transformation across two formats: PDF to XLSX. Time savings were confirmed qualitatively, but were not historically measured and are not quantified here.

## Learnings

Turning a document into useful structured data means treating delivery as part of the product. This public version preserves that lesson without exposing financial documents, personal data, or messages.

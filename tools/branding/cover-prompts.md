# Prompts e direcionamento para capas do portfólio

Use estes prompts como base para criação no Canva, Figma ou geradores de imagem. A recomendação é sempre ajustar manualmente o texto final para garantir legibilidade.

## Regras gerais

- formato horizontal `1200x630`
- layout limpo e profissional
- tipografia forte e legível
- visual moderno, técnico e corporativo
- pouco texto
- sem aparência de thumbnail sensacionalista

## Template de texto para qualquer capa

- categoria
- título do projeto
- subtítulo curto
- stack principal

## Prompt mestre para IA de imagem

Crie uma capa horizontal 1200x630 para portfólio profissional de tecnologia e dados, com design limpo, corporativo e moderno. Use fundo sofisticado, contraste alto, tipografia clara e hierarquia visual forte. Inclua espaço para categoria, título do projeto, subtítulo curto e stack principal. Evite visual sensacionalista, excesso de elementos ou aparência genérica de thumbnail. Use elementos gráficos sutis relacionados ao tema do projeto, como dashboards, linhas de dados, automação, mapas ou blocos analíticos.
